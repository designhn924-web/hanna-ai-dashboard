# layout

ダッシュボード全体の骨格(ヘッダー・サイドバー・機能ページ共通レイアウト)を置きます。

- `DashboardHeader.tsx` — 全ページ共通のヘッダー
- `DashboardSidebar.tsx` — 6機能への遷移用サイドバー
- `FeatureLayout.tsx` — 各機能ページの共通レイアウト(見出し + 左右パネル)
- `navItems.tsx` — サイドバー・トップページのメニュー一覧で共有するナビゲーション項目

特定の機能に依存しない、画面の「枠組み」だけを担当します。
機能ごとの中身は `features/` 配下に置いてください。
